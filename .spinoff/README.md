# `.spinoff/` — material de referência do processo

Esta pasta **não é entrega do projeto**. É a cópia local do método SpinOff
(<http://arum.tec.br/SpinOff/index.htm>), guardada aqui para que o grupo tenha os templates e
os guias à mão sem depender do site — e para que o Claude Code consiga consultar o processo
sem acesso à internet.

Ela começa com ponto (`.spinoff`) de propósito: fica fora da estrutura numerada de disciplinas
que o processo define para os artefatos do projeto.

## Conteúdo

| Item | O que é |
|---|---|
| [METODO.md](METODO.md) | Referência completa: fases, marcos, WBS, tarefas com passos, papéis, artefatos, convenções de nomeação e branches, mapa artefato→pasta |
| [GUIAS.md](GUIAS.md) | Texto integral dos guias publicados como página: FURPS+, Entrevista, Workshop de Requisitos, INVEST, VRDC, Políticas de GC, Abordagens de Teste |
| [templates/](templates/) | Os 10 templates oficiais (`.dotx`, `.xltx`, `.asta`) + `Estrutura-Projeto.zip` |
| [guias/](guias/) | Guias publicados como PDF |

## Onde os artefatos do projeto realmente vão

Nas pastas numeradas na raiz do repositório (`1.Requisitos/` … `6.Gerenciamento de Projeto/`).
O mapa completo está em [METODO.md § Onde cada artefato é armazenado](METODO.md#onde-cada-artefato-é-armazenado).

## Atualizar esta cópia

O site é estático. Para re-espelhar, basta baixar de novo a partir de
`http://arum.tec.br/SpinOff/noapplet/spinoff_view_46902872.html`, que lista todas as páginas.
